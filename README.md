# Third-Party Cybersecurity Risk Assessment Questionnaire

## Project overview
This repository contains the technical report and supporting documentation for a desk-based
questionnaire design project for initial cybersecurity review of software and service providers.

The questionnaire design covers governance and risk management, access controls, data handling
and privacy, incident response, backups and continuity, vulnerability management, and
subcontractors and assurance evidence.

## Scoring approach
The report proposes the following initial scoring: Yes = 2, Partially = 1, No = 0, Unknown = 0,
and Not applicable is excluded only with a reasonable justification. Score (%) = points earned
divided by maximum points for applicable questions, multiplied by 100. The score bands are
illustrative project criteria and are not validated or mandated by the cited frameworks.

## Important scope note
This repository documents questionnaire design and a proposed evaluation method. It does not
claim that an actual provider was assessed, that provider evidence was verified, or that a live
technical control test was completed.

## Safety
Do not commit passwords, API keys, personal data, confidential vendor records, or other secrets.
